# VPS Security Bootstrap v10.1.0

本版本扩展常用 VPS 发行版支持，并提高通用流程的可控性。

## 新功能

- 支持 Debian、Ubuntu、RHEL、CentOS Stream、Rocky Linux、AlmaLinux、Oracle Linux、Fedora 和 Amazon Linux。
- 自动选择 apt、dnf 或 yum。
- Debian/Ubuntu 使用 UFW 与 unattended-upgrades。
- RHEL/Fedora 系优先使用 firewalld，并使用 dnf-automatic 或 yum-cron。
- SELinux 启用时，为新的 SSH 端口登记 `ssh_port_t`；SSH 回滚时同步撤销本次登记。
- 通用安全开荒的预检及 1-12 步均可选择执行、跳过或停止。
- 主菜单加入 IPv6 开启/关闭，使用独立 sysctl 配置，并提供备份、校验与失败回滚。

## 安全说明

- 跳过密钥测试不会直接关闭密码认证；执行关闭密码认证时仍会检查公钥并要求人工确认。
- 关闭 IPv6 会立即中断 IPv6 连接，但不会删除云厂商分配的 IPv6 资源。
- Alpine、OpenWrt 等非 systemd 系统暂不支持。
