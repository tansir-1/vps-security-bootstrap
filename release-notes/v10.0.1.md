# VPS Security Bootstrap v10.0.1

[中文](#中文) | [English](#english)

## 中文

v10.0.1 是 v10.0.0 的安全与可靠性审计修复版本。

### 重点修复

- 修正自定义 nftables 与未启用 UFW 的识别优先级。
- 新增自定义 iptables 检测，并保持只读保护。
- firewalld 使用默认路由网卡实际 active zone。
- install.sh 与 Copy-Paste 版本使用随机 mktemp 临时文件并自动清理。
- Copy-Paste 包运行于独立子 Shell，失败不会退出当前 SSH 会话。
- SSH 新端口确认成功后，旧端口 ALLOW 不再静默删除。
- SSH 事务回滚可恢复原本不存在 authorized_keys 的状态。
- 修复 UFW 未启用时 IPv6 防火墙状态误报。
- Fail2ban sshd jail 增加实际端口生效验证。

### 工程化

- CI 新增 install.sh 检查和静态安全不变量测试。
- GitHub Actions 依赖固定到 commit SHA。
- 自动生成正式脚本、Copy-Paste 包和 SHA256SUMS。

## English

[Back to 中文](#中文)

v10.0.1 is a security and reliability audit release for v10.0.0.

### Highlights

- Fix firewall-backend priority for inactive UFW plus custom nftables.
- Add read-only detection for custom iptables INPUT rules.
- Resolve the active firewalld zone from the default-route interface.
- Use randomized mktemp files and automatic cleanup in the installer and Copy-Paste build.
- Run Copy-Paste payloads inside a subshell so failures do not terminate the parent SSH session.
- Never silently remove the old SSH firewall ALLOW rule after a port migration.
- Restore the absence of authorized_keys during rollback when appropriate.
- Fix IPv6 firewall status when UFW is inactive.
- Verify the effective Fail2ban sshd jail port.
- Expand CI and automate release assets with SHA256SUMS.
