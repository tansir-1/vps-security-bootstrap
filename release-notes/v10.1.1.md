# VPS Security Bootstrap v10.1.1

2026-11-06 发布的安全与可靠性修复版。

- 阻止未完成 SSH 事务被后续操作覆盖；必要快照或配置写入失败时停止。
- 保留现有 root 登录策略，修复 systemd 状态重复记录。
- UFW 检查重叠范围、REJECT、来源限制与已保存简单规则，写入失败不再误报成功。
- firewalld 拒绝冲突时停止；同时维护运行和永久规则，避免全量 reload 丢失运行时业务规则。
- 未运行的 firewalld 不再自动启动，需控制台离线预配置。
- 十进制端口规范化、终端 EOF 退出、单实例锁与原子状态文件。
- IPv6 仅应用托管配置，失败时恢复已备份的内核运行值。
- 无终端只读审计不会安装依赖。
- 增加行为回归测试，CI 升级到 ShellCheck warning 级别；修正 Release 校验清单附件名，停止覆盖同名附件。

完整发现和验证边界见 [安全检查记录](../docs/SECURITY-REVIEW.md)。本版尚需 Linux VM 集成验收，未提供无人值守的定时 SSH 自动回滚。
