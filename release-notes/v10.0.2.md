# VPS Security Bootstrap v10.0.2

这是针对 Debian 12 / Fail2ban 1.0.2 的兼容性修复版本。

## 修复内容

- 移除 Fail2ban 1.0.2 不支持的 `fail2ban-client get sshd port` 查询。
- Fail2ban 配置现在先通过 `fail2ban-client -t` 完整检查，再重启服务。
- 重启后继续确认 `sshd` jail 正常运行，失败时仍会触发原有 SSH 事务回滚。
- 固定脚本、测试和发行文件使用 LF 换行，避免 Windows Git 检出后破坏 Bash 语法或校验值。

## 影响

修复以下误报：

- 安装 Fail2ban 时显示端口校验失败。
- 修改 SSH 端口时误报 Fail2ban 未同步，并将 SSH 端口回滚。

---

This patch release fixes compatibility with Fail2ban 1.0.2 on Debian 12.

## Fixes

- Removes the unsupported `fail2ban-client get sshd port` query.
- Validates the complete Fail2ban configuration with `fail2ban-client -t` before restarting the service.
- Continues to verify that the `sshd` jail is running after restart, preserving the existing SSH transaction rollback behavior on real failures.
- Enforces LF line endings for scripts, tests, and release artifacts so Windows checkouts do not break Bash syntax or checksums.
