# VPS Security Bootstrap v10.2.0

单项安全优化新增 **13. 入侵痕迹排查（只读）**，整合用户提供的服务器检查脚本。

- 30 组信息：进程、临时/已删除可执行文件、端口/连接、SSH 配置/日志、账户/密钥、Cron/systemd/Shell 持久化、preload、文件权限、容器、主机防火墙及内核模块。
- 动态端口识别、双 SSH unit 日志、非 root UID=0 检查；所有匹配仅供人工复核。
- 外部命令超时、输出字节/行数、目录深度和数量限额；缺少命令、失败及截断明确记录。
- 报告保存于 root 私有目录，权限 600；过滤终端控制字符，退出时清理临时采集文件。
- 不执行被检查文件、不自动删除/停止/修复、不安装扫描器、不上传报告。
- 新增入侵模块自动测试，保留现有安全回归/UI/入口检查。

报告可能含凭据，分享前请脱敏；未发现特征不能证明未被入侵，不能依赖本机工具排除 rootkit。[使用范围与判读](../docs/INTRUSION-AUDIT.md)。

**永久运行命令不变**：README 继续使用 `main/install.sh`，安装器默认版本更新为 10.2.0，保留旧版本固定哈希。无需更改 SSH 脚本库中的命令，也无需为了升级工具重新执行加固步骤。
