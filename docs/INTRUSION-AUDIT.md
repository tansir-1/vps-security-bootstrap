# 入侵痕迹排查（只读）

入口：主菜单 **2. 单项安全优化 → 13. 入侵痕迹排查（只读）**。确认后开始采集，不自动加入通用开荒流程。原有 1–12 和 0 的动作保持不变。

整合了用户提供的服务器体检脚本，直接包含在主脚本及复制粘贴发行包中；不会创建或执行额外的 `/root/security-audit.sh`，也不会下载扫描器或安装依赖。

## 采集范围

保留原脚本的 30 组检查：

1. 系统、内存、文件系统；2. CPU/内存高占用进程；3. 矿工/扫描器名称特征；4–5. 临时路径和 deleted 可执行文件；6–7. 监听及连接；8. SSH 配置；9–10. SSH 成功/失败登录及账号/IP汇总；11. 登录历史；12. UID=0 和登录账户；13. authorized_keys 元数据/指纹；14. sudoers；15–16. 用户及系统 Cron；17–19. systemd 定时任务/启用服务/本地单元；20. 启动项和 Shell 配置；21. ld.so.preload；22–23. 临时目录脚本/可执行/SUID/SGID；24. usr/local 最近文件；25. Docker 容器权限及挂载；26. 主机防火墙；27. 内核模块；28. 关键目录最近修改；29. 可疑命令行模式；30. 实际 SSH/业务监听复核。

相对粘贴脚本的调整：

- 去掉用户服务器专属端口，读取实际 sshd 配置和监听信息。
- 同时读取 `ssh.service` 和 `sshd.service` 的日志，按新到旧采集，避免截断时优先丢掉近期记录。
- 即使只有一个 UID=0 账户，只要名称不是 root，也提示人工确认。
- `bioset`、`watchdogd` 等通用名称不单独作为恶意进程标记；关键词匹配始终只表示待复核。
- 合并一次 /proc 遍历，读取可执行文件路径和最多 4 KiB 命令行，不执行目标文件。
- 公钥只显示元数据及指纹；Docker 只读取指定元数据/挂载，不输出完整 inspect 或 Env。
- 补充 firewalld / iptables 的只读查询；缺少命令、权限失败、超时和输出截断均明确记录。

## 报告与隐私

报告保存为 `/root/vps-security/reports/intrusion-<时间>-<随机值>.txt`，权限为 `600`；目录沿用工具的 `700` 权限。临时采集目录在退出时清理，报告和操作日志保留。终端控制字符在输出及保存前过滤，报告不带 ANSI 颜色。

报告可能包含真实 IP、账户、进程参数、Cron/Shell 配置、容器挂载路径，甚至配置中的凭据。**分享前手动脱敏，不要公开整个报告或备份。** 工具不会自动上传或发送报告。

## 有界采集与结果含义

每个外部采集命令最多约 20 秒，超时终止的是本次采集的子命令，另有 2 秒终止宽限。全局时间预算为 180 秒，用尽后跳过后续命令。单次输出最多 256 KiB，各项还有限制行数。SSH 日志请求最近 30 天、最多 20000 条，并受输出上限影响；临时/关键目录最多递归 4 层，/proc 最多遍历 5000 项、显示前 100 条待复核进程，用户/密钥/容器均有数量上限。报告会说明跳过、截断或未采集信息。

- `[WARN]`：存在需要人工确认的特征，**不等于已被入侵**。
- `[UNAVAILABLE]`：缺命令、读取失败、超时、限额等导致未能完整检查，**不能按干净处理**。
- `[INFO]` 或未匹配：仅说明已采集内容的观察结果，**不能证明服务器未被入侵**。

deleted 可执行文件可能来自正常软件升级，preload 也可能来自合法软件。日志可能已轮转、未持久化或被删除；自定义日志和 SSH Match 上下文需要另外核查。本工具依赖当前系统的内核、进程和本地命令，不能作为 rootkit 的可信排除手段。对确认受影响的主机，应保留证据并从可信环境进一步核验；不要按本报告直接删除未知文件或进程。

## 验证

`python3 tests/intrusion.py` 使用合成的进程、账户、日志和命令输出检查菜单入口、30 组采集、双 SSH unit、动态端口、失败/超时处理、输出上限、报告写失败、控制字符、取消、临时目录清理及只读文件处理。Linux CI 额外检查真实符号链接和报告 600 权限。

测试不等于真实受侵主机上的检出率验证，不对已控制本机内核/日志/工具的攻击者作检测保证。

命令语义核对：[systemd journalctl](https://www.freedesktop.org/software/systemd/man/256/journalctl.html)、[Linux /proc 文档](https://www.kernel.org/pub/linux/docs/man-pages/book/man-pages-6.13.pdf)、[Docker inspect](https://docs.docker.com/reference/cli/docker/inspect/)。
